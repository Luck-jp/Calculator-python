# 🧮 Python Calculator

A simple command-line calculator built using Python.

---

## 🚀 Features

* Addition (+)
* Subtraction (-)
* Multiplication (*)
* Division (/)
* User input based interaction

---

## 🛠️ Tech Used

* Python 3

---

## ▶️ How to Run

1. Clone the repository:
   git clone https://github.com/Luck-jp/Calculator-python.git

2. Navigate to the folder:
   cd Calculator-python

3. Run the program:
   python main.py
